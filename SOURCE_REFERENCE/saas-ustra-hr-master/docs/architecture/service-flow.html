2 요청 한 건이 지나는 경로

브라우저가 보낸 HTTP 요청 하나가 DB 에 닿았다가 돌아오기까지의 단계다.

STEP 0 · 브라우저
$.ajax / 폼 전송
공통 Ajax 프리필터가 스피너를 제어하고, XHR 에는 X-Requested-With 헤더가 붙는다.
STEP 1
LogFilter
최우선 순위 필터. 요청 단위 접속 로그를 남긴다.
STEP 2
Lucy XSS Filter
파라미터 XSS 이스케이프. 룰은 lucy-xss-servlet-filter-rule.xml.
STEP 3
JWT 인증 필터
쿠키 토큰 검증 → 서버명 대조 → DB 토큰 존재 확인 → SecurityContext 설정.
STEP 4
권한 판정
정적 권한 목록 + AuthorizationChecker 의 동적(메뉴/프로그램) 권한 검사.
STEP 5
DispatcherServlet → Controller
인터셉터(Referrer·로그인설정) 통과 후, 쿼리스트링·폼을 DTO 로 바인딩. 화면이면 *Web, 데이터면 *RestController.
STEP 6
Service (@Transactional)
업무 규칙 적용. 트랜잭션은 이 계층에서 시작·종료된다.
STEP 7
Mapper / Repository
MyBatis 인터페이스 ↔ sqlmap XML 의 SQL. 일부 기능은 JPA Repository.
STEP 8 · DB
HikariCP → MariaDB
log4jdbc 를 거쳐 실제 SQL 실행. 결과는 CamelCaseMap/DTO 로 매핑되어 역순으로 돌아간다.

3 로그인 · 인증 흐름 (JWT)

폼 로그인으로 발급한 JWT 를 쿠키에 담고, 이후 모든 요청을 필터가 검증한다. 토큰은 DB 에도 저장되어 서버 측에서 즉시 무효화할 수 있다.

토큰이 만료되면 필터가 Refresh 토큰으로 재발급을 시도한다. 재발급도 실패하면 — Ajax 요청은 HTTP 419 를 받고, 일반 요청은 로그인 화면으로 이동한다. 토큰의 serverName 이 서버 설정과 다르거나 DB 토큰 스토어에 없으면 즉시 로그아웃 처리된다.

4 업무 화면 — 조회 · 저장 흐름

업무 화면 대부분은 그리드 중심이다. 조회는 GET, 저장은 변경분(C/U/D)을 한 번에 POST 하는 방식이다.

화면 코드는 UstraRealGrid API 그대로 호출하고, 호환 어댑터가 이를 TOAST UI Grid 로 옮긴다. 따라서 그리드 엔진을 바꿔도 화면 HTML · Java · Mapper 는 변경되지 않는다.

5 화면 진입 (SSR) 흐름

데이터 조회와 달리, 화면 자체는 서버가 Thymeleaf 로 렌더링해 HTML 로 내려준다.

순서위치동작
1사용자좌측 메뉴에서 업무 메뉴를 클릭한다.
2프론트sidelayout 이 MDI 탭을 추가하고, 해당 화면 URL 로 iframe 을 연다.
3서버필터 체인 통과 후 @Controller(*Web)가 요청을 받고, 메뉴/프로그램 권한을 검사한다.
4서버Thymeleaf 가 framelayout 을 decorate 해 화면 HTML 을 생성한다. 이때 ustra.grid.engine 설정(또는 ?gridEngine=)에 따라 그리드 스크립트를 택일 로드한다.
5프론트iframe 안에서 HTML 이 로드되고, 부모의 테마 클래스를 복제한 뒤 그리드를 생성한다.
6프론트 → 서버화면 초기화 시 공통코드·부서·사원 등 기준정보를 /api/** 로 비동기 조회한다. (이후는 4장 흐름과 동일)

7 모듈 의존 방향

실행 가능한 산출물은 thymeleaf · restapi 두 개뿐이고, 나머지는 라이브러리로 묶인다.

화살표는 “의존한다” 방향이다. ustra-hr-system-report 는 settings.gradle 에 등록되어 있으나 소스가 없다.

운영 시 알아둘 점
  • spring.profiles.active 는 모듈 설정 로딩용(core, web, api)과 환경(local/dev1/dev2/prod1/prod2)이 함께 지정된다.
  • spring.security.filter.dispatcher-types 를 async, error, request 로 고정해야 한다. FORWARD 까지 태우면 로그인 실패 시 무한 forward 로 StackOverflowError 가 난다.
  • 그리드 엔진은 동시에 두 개를 로드할 수 없어 서버사이드에서 택일한다. 되돌리려면 ustra.grid.engine: realgrid 한 줄만 바꾸면 된다.
  • DB 접속 정보 등 민감값은 Jasypt 로 암호화해 커밋한다. 평문 금지.
