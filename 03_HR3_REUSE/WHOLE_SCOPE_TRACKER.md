# 대한제분 HR 전체 기능 범위: 도메인 수준 1차 Backlog

HRP 관련 화면·계산·결재는 고객 기존 HRP 사용 예정으로 **이번 Target 개발 분모에서 제외**합니다. 상세 기능 건수 및 난이도는 대한제분 확정 BPD와 HRP 경계 승인본에 매핑 후 확정합니다.

| 우선순위 | 영역 | 1차 Executable Slice 후보 | 상태 |
|---|---|---|---|
| P0 | Runtime Foundation | 빌드, 기동, 인증·인가, 테스트 DB, 로그 | 기동 미검증 |
| P0 | 인사 기준정보 | 조직·법인·사원 조회/권한 | 기동 후 우선 |
| P1 | 조직·인사발령 | 기준일자 조직/직무/발령 이력 | 미착수 |
| P1 | 근무규칙·스케줄 | 적용기간·유형·교대·계획 | 미착수 |
| P1 | 출퇴근/근태·휴가 | 일근태, 시간휴가 조회, 근태 수정과 승인 | 미착수 / 정책 HOLD 구간 분리 |
| P1 | 근태 월마감 | 수량·마감 Snapshot, 재집계 경계 | 미착수 / Golden HOLD |
| P1 | 급여·정산 | 계산·조회·마감·소급, 근태 반영 | 미착수 / Golden HOLD |
| P2 | 교육·자격·경력 | 교육·직무·역량·자격·경력 | 미착수 |
| P2 | 직원서비스/복지 | 신청·조회·처리·알림, WORKS/ITSM 계약 | 미착수 |
| P2 | 운영 도구·대시보드 | 대량 업로드·대사·오류 재처리·통계 | 미착수 |
| OUT | HRP | 평가/HRP 개발 | 고객 기존 HRP 담당 |

**개발률(새 Target)**: 분모 미확정이므로 수치 미산정. 검증 완료율: 미산정. 실행 준비도: Source/Script Prepared, Gradle Blocked. 지표는 다음 Increment부터 확정 증거로 갱신합니다.
